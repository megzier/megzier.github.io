## 🎨 Animation Details

### Keyframes Used:
```css
@keyframes fadeInUp {
    from: opacity 0, translateY(30px)
    to: opacity 1, translateY(0)
}

@keyframes scaleIn {
    from: opacity 0, scale(0.8)
    to: opacity 1, scale(1)
}

@keyframes slideInLeft {
    from: translateX(-50px)
    to: translateX(0)
}
```

### Timing:
- **Fast:** 0.3s (buttons, links)
- **Medium:** 0.6s-0.8s (text, cards)
- **Slow:** 1s (images, sections)

### Easing:
- All animations: `ease-out`
- Smooth, natural motion
- Professional feel
